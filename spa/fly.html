Workload Identity Token (WIT)

A WIT is a signed JWT that proves a workload's SPIFFE identity. Unlike a password, it is cryptographically bound to the workload's own key pair — it can only be used by the entity that holds the private key.

Workload Authorization Grant (WAG)

WAG lets a workload get an OAuth access token with zero pre-registration at the AS. The platform (SPIRE) registers once. Every workload it vouches for is accepted automatically — critical for ephemeral containers and AI agent fleets.

Architecture

Three Go services, each a Dockerfile. Three Fly.io VMs on the free tier. One Cloudflare Pages SPA. All inter-service calls use real HTTP with real JWTs.
